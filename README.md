# Vibly – Place Discovery App
### Find your vibe. Find your place. 💜

## 1. Project Name
**Vibly – Place Discovery App**

## 2. Project Idea

### About the Project
Vibly is a place discovery app that helps people find places that match their mood, purpose, and personal preferences.

Whether you're looking for a quiet café to study, a comfortable workspace, or a restaurant to spend time with friends, Vibly makes it easier to find a place that fits what you're looking for.

Instead of depending only on general ratings and photos, users can explore places based on details that matter to them, such as noise levels, crowd levels, internet quality, prices, available facilities, and reviews from people with similar needs.

**The main idea is simple:** helping people spend less time searching and make better choices about where to go.

## 4. Work Plan

We followed a user-centered design process to understand the problem, learn about users, and build a solution based on their actual needs.

**Step 1 – Project Understanding**
- Define the project idea and its main goal.
- Identify the problem Vibly aims to solve.
- Understand the value the app will offer to users.

**Step 2 – Market Research**
- Research the target market.
- Identify market opportunities and challenges.
- Analyze 3–5 competitors.
- Compare their strengths and weaknesses to find opportunities for Vibly.

**Step 3 – User Research**
- Define research objectives and questions.
- Prepare and share a survey with the target audience.
- Conduct user interviews.
- Analyze responses and extract key insights.
- Organize findings using an Affinity Map.

**Step 4 – Define**
- Create User Personas based on research findings.
- Prepare Empathy Maps.
- Identify the main user Pain Points.
- Write Problem Statements.
- Use the 5 Whys technique to understand the root causes.
- Suggest solutions based on the problems discovered.

**Step 5 – User Experience Structure**
- Create User Journey Maps.
- Conduct Card Sorting to organize the content.
- Build the Information Architecture and Sitemap.
- Create User Flows for the main tasks.

**Step 6 – Design & Testing**
- Create Wireframes.
- Build a Low-Fidelity Prototype.
- Test the design with real users.
- Collect feedback and make improvements.
- Move on to UI Design and the High-Fidelity Prototype.

## 5. Roles & Responsibilities

The team works together across the different stages of the project. Responsibilities include:

- **Project Planning:** Organizing tasks, setting priorities, and following up on progress.
- **UX Research:** Conducting surveys, interviews, market research, and competitor analysis.
- **UX Analysis:** Analyzing research results, creating personas and empathy maps, and identifying user problems.
- **UX Design:** Working on user journeys, card sorting, information architecture, sitemaps, and user flows.
- **UI Design:** Creating the visual design, design system, and application screens using Figma.
- **Prototyping & Testing:** Building prototypes, testing the experience, collecting feedback, and improving the design.

## 6. KPIs – Key Performance Indicators

We use these indicators to evaluate how well Vibly meets users' needs:

- **Task Success Rate:** How many users can complete the main tasks successfully.
- **Task Completion Time:** How long it takes users to find a suitable place.
- **User Satisfaction:** How satisfied users are with the overall experience.
- **Ease of Use:** How easily users can understand and navigate the app.
- **Recommendation Relevance:** How well suggested places match users' purposes and preferences.
- **Filter Effectiveness:** How easily users can find places using the available filters.
- **User Feedback:** The problems and suggestions users share during testing.
